How It Works

OpenUTM provides end-to-end airspace management through three core capabilities.

1

Remote ID

Every drone broadcasts its identity and position. OpenUTM receives and processes this data in real-time, creating a complete picture of all aircraft in the airspace.



2

Strategic Deconfliction

Before takeoff, flight plans are checked for conflicts with other operations, restricted areas, and manned aircraft. Approvals are automated and compliant with ASTM standards.



3

Real-Time View

Operators and regulators see all aircraft on a unified map. Flight Spotlight provides 3D visualization, timeline playback, and alerting for complete situational awareness.

Built for Standards Compliance

Flight Blender is compatible with the following UTM standards

As the standards are developed and evolve, Flight Blender will maintain compatibility with them so that you are always current.

  • ASTM F3411-22 Standard specification for Remote ID and Tracking
  • Authorize flights in the context of conflicts and incorrect data (strategic deconfliction) via ASTM F3548-21
  • Consume and utilize geofences per the ED-269 data format and standard.
  • Customized implementation to accept Airtraffic data from sources such as ADS-B.
