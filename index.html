Built for Standards Compliance

Flight Blender is compatible with the following UTM standards

As the standards are developed and evolve, Flight Blender will maintain compatibility with them so that you are always current.

  • ASTM F3411-22 Standard specification for Remote ID and Tracking
  • Authorize flights in the context of conflicts and incorrect data (strategic deconfliction) via ASTM F3548-21
  • Consume and utilize geofences per the ED-269 data format and standard.
  • Customized implementation to accept Airtraffic data from sources such as ADS-B.
